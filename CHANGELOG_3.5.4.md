# DVS AI Alpha 3.5.4 — Responsive Decision Workspace

## Fixed
- Eliminated visual overlap/clipping between Qualification, Analytics, Evidence and Conclusion panels.
- Decision Core now remains usable on 1366×768 and other short desktop viewports.

## Added
- Three-page Decision Core workspace: **Tổng quan**, **Evidence**, and **Kết luận & giải thích**.
- Independent scrolling for the overview page.
- Resizable, non-collapsible Evidence table/detail splitter.
- Practical minimum heights and widths for evidence inspection.
- Interactive evidence columns, alternating rows and hidden row header for improved readability.

## Safety boundary
- UI-only release. No decision logic, qualification thresholds, execution authority, exchange connectivity or shadow runtime policy changed.
- Unified Core remains SHADOW_ONLY; Paper Authority remains LEGACY.
