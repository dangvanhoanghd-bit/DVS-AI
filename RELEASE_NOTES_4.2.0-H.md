# DVS AI Alpha 4.2.0-H

## Research Governance Dashboard & Review Coverage

Adds a read-only governance dashboard across the Research Workspace and isolated review ledger.

- review coverage by target type
- approval-state distribution
- unreviewed research artifacts
- checksum-integrity drift and orphan reviews
- reviewer workload and annotation coverage
- JSON and HTML governance export

Scientific boundary: governance metadata only; no result mutation, tuning, Decision Engine invocation, canonical database write, signal creation, or order execution.
