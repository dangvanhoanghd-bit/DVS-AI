# DVS AI Alpha 4.3.0D-3 — Uncertainty & Association Diagnostics

Adds a cluster-aware, deterministic bootstrap uncertainty layer for historical evidence studies.

## Included
- Effective sample size based on market-event cluster concentration.
- Observed-versus-missing evidence cohort comparison.
- Cluster bootstrap percentile confidence intervals.
- Sign stability diagnostics.
- UNOBSERVABLE / INCONCLUSIVE / ASSOCIATED / ROBUST_ASSOCIATION classification.
- Self-sealed result and manifest export with an independent verifier.

## Scientific boundary
Results are historical associations, never causal claims. Decision Engine, TradePlan, outcomes, MAIN, SHADOW and execution authority remain untouched.
